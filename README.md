# FormFlow Status

Status page pública de [FormFlow](https://formflow.app), generada con
[Upptime](https://github.com/upptime/upptime) — monitoreo de uptime 100% en GitHub
Actions, sin servidores propios.

- Config: [`.upptimerc.yml`](.upptimerc.yml)
- Chequeo de sitios cada 5 minutos ([`uptime.yml`](.github/workflows/uptime.yml))
- Setup pendiente (DNS): ver [`SETUP.md`](SETUP.md)

Una vez el deploy real de FormFlow esté arriba, la status page se publica sola vía
GitHub Pages en `status.formflow.app`.
